🔧 首次联网配置

GitHub Pages 只能托管网页；要让所有手机实时共享票数，需要连接 Firebase Realtime Database。

将 Firebase 控制台提供的 databaseURL 填入下方，保存后刷新即可。请先按页面说明配置数据库访问规则。

注意：仅配置地址不足以保障投票安全；临时开放数据库写权限会让知道网址的人也能改票。正式使用前应配置身份验证与数据库规则。
